# 机柜设备管理使用说明

## 从源码启动

在项目目录执行：

```powershell
.\venv\Scripts\python.exe -X utf8 -m src.main
```

进入“设备管理”，默认显示机柜视图；右上角三个图标可以选择机柜、列表、方块视图，并保存选择。

也可在启动命令末尾添加 `--devices`，直接打开设备管理页。未创建机柜时展示的是机柜外观示意，点击“创建第一个机柜”保存真实机柜；已有设备以拟物服务器面板显示在待上架区，点击后可安排位置。机柜和服务器使用 Qt 原生矢量绘制，支持缩放，服务器面板显示硬盘托架、散热网、铭牌和连接状态灯。

## 创建机柜与设备上架

1. 点击“新增机柜”，填写编号、名称、机房和容量。默认 42U，支持 1–60U。
2. 点击“添加”，或直接点击机柜内的空槽。
3. 填写设备 SSH 信息，选择机柜、起始 U 位和高度。也可以选择“暂不上架”。
4. 起始 U 位是设备底部。例如起始 U09、高度 2U，实际占用 U09–U10。
5. 点击“推荐空位”查找第一段连续空槽，或自行选位。冲突和越界会明确提示，不会挤动已有设备。
6. 保存后点击设备面板，右侧显示该设备的详情和操作。

旧设备不会被自动塞入机柜，统一显示在“待上架设备”区域；点击设备，选择“调整位置 / 下架”，再填写位置。

## 点击设备后可以做什么

- 连接设备，或断开当前设备。
- 一键巡检：连接成功后启动当前勾选的巡检项；可先在巡检页调整勾选项。
- AI 排障、日志收集：进入对应页面，由用户继续操作。
- 实时监控：打开目标设备的监控窗口。
- 调整位置、迁移到其他机柜，或选择“暂不上架”将设备下架。
- 查看最近一次手动巡检摘要，以及已实际导出的报告文件。

齿轮菜单继续提供切换 root、编辑、删除、知识库和脚本库。切换 root 的可用状态与当前登录及连接状态一致。

系统沿用单个主运维会话。操作另一台设备时会提示切换连接；连接失败或取消后不启动巡检。巡检、AI 排障命令、日志提取和报告分析运行期间，需要先等待或停止任务再切换设备。连接中的目标设备不能编辑或删除。

“已连接”仅表示 SSH 会话可用；“未连接”不代表设备离线。最近巡检结果与连接状态分别显示，并附带巡检时间。定时巡检继续使用原有页面和报告目录，不写入第一版机柜详情的手动巡检摘要。

## 管理和检索

搜索可按设备名称、IP、产品或机柜查找；机房下拉框筛选机柜。搜索不会改变设备真实 U 位，匹配的设备面板高亮显示。

机柜容量可以修改，但缩小后不能使任何设备越界。删除机柜前必须迁移或下架全部设备。下架保留设备连接配置；删除设备继续需要确认，当前已连接设备需要先断开。

已有位置异常的设备进入“位置待修复”区，不参与有效占用率统计。允许逐条修复旧记录；未修改的旧异常记录暂时保留。新增位置和修改后的位置必须有效，不能引入新的冲突或越界。

## 保存与兼容

源码模式使用 `src/config/servers.json` 保存设备、机柜和视图偏好。旧格式首次成功保存前生成 `servers.json.v1.bak` 本地备份；原子替换保存失败时保留原文件。读取配置失败时禁止覆盖原文件，需先修复配置再重启。

最近手动巡检摘要位于同目录 `inspection_history.json`，包含设备 ID、时间、计数和实际导出的报告路径，不保存密码。报告移走后会提示文件不存在。以上本地配置、备份和巡检输出均不提交到 Git。

## 毕业设计可讲的实现

机柜空间用整数区间建模：设备从 `start` 到 `start + height - 1`。两个区间 `[a,b]` 和 `[c,d]` 在 `max(a,c) <= min(b,d)` 时重叠；从低位向高位扫描即可推荐连续空位。

界面、空间规则和 SSH 调度分开：界面发出设备 ID 和动作，主窗口校验目标、建立连接并启动任务。连接请求令牌用于忽略过期回调，巡检开始时冻结设备快照，结果和报告始终绑定启动目标。

巡检状态仍由现有采集规则判定，AI 根据实际输出辅助解释。没有 AI 配置时，基础巡检和原始报告导出仍可独立使用。
