# 代码审查与优化记录

日期：2026-11-04

本次检查设备管理、机柜绘制与拖放、单台和批量巡检、SSH 命令执行及相关窗口生命周期。

## 已修复的逻辑问题

| 问题 | 修复 |
| --- | --- |
| 刷新批量设备列表后，选中行可能变化，输出和导出目标仍是上一台设备 | 按设备 ID 保留选择；目标被删除时清空结果并禁用导出；结果显示采集时间 |
| sudo 密码拼接在命令中，可能被 shell 解释或调试输出记录 | 通过 SSH 标准输入发送密码，命令参数使用标准 shell 转义；不输出凭据 |
| `sudo whoami` 只验证一次，但界面将整个连接误标为 root | 验证成功后，每条远程命令通过 sudo 执行；保留真实 SSH 登录用户，单独记录有效权限 |
| 命令超时后仍等待退出码，可能继续阻塞 | 到达期限后返回超时并关闭命令通道 |
| 流式执行没有处理标准错误，停止后通道未关闭 | 同时读取标准输出和错误输出；停止、异常及关闭生成器时统一释放通道 |
| 退出检查遗漏正在连接和定时巡检的线程 | 退出前检查这些活动任务，避免销毁仍在运行的线程 |

root 命令模式只影响远程命令；文件上传、下载使用 SSH 登录账户权限。sudo 密码只保留在连接对象内存中，断开时清除。更换连接目标不会继承上一个目标的 sudo 状态。

## 清理

- 移除命令、原始巡检数据和模型配置的调试打印，以及自动写入用户目录的原始输出调试日志。
- 删除无调用的同步模型请求、旧测试报告入口、重复报告模板、旧页面跳转和相关信号。
- 主窗口复用设备管理的密码读取逻辑，减少重复实现。
- 清理旧的内嵌巡检命名、重复导入和调试计数。
- 删除 root 切换成功弹窗和最小化提示，状态由当前界面体现。连接失败、保存失败、任务冲突和删除确认继续保留。
- 将“AI 思考中”等文案改为“正在分析”，缩短机柜空状态和操作说明。

## 浅色机柜与动画

机柜和服务器改为银白、浅蓝灰金属配色，保留槽位、托架、散热孔和状态灯。

悬停和选中使用短渐变；设备落位使用淡入过渡；连接或巡检中的状态灯缓慢变化。动画只作用于绘制，不改变设备控件位置或 U 位计算。隐藏页面会停止动画，避免持续刷新。

## 验证范围

125 项自动测试通过，包含本地 SSH 服务的真实认证与命令收发、模拟 sudo 标准输入、错误流、超时、生成器关闭、批量目标绑定、退出保护、拖放与动画生命周期。Qt 截图检查了浅色机柜、空状态和设备详情。

没有连接用户的真实 Linux 主机；具体服务器的 sudo 授权和系统差异仍需在测试环境验证。本次没有更改现有设备配置格式或已有巡检报告。

## 按钮与设备详情补充检查

按钮改用共享配色：主操作深青绿、普通操作白底、停止与删除浅红底，禁用状态使用灰色文字与背景。模型配置页明确区分保存、连接测试与返回。共享规则覆盖后创建的弹窗，以及发送切换为停止等动态状态；机柜设备绘制和导航控件保留各自行为。日志页选中标签及列表使用更深的青绿色，改善白字对比度。

设备详情默认隐藏，点击设备后显示，右上角关闭按钮清除选中状态；状态刷新和拖动落位不会重新打开已关闭的详情，也不会断开当前连接。
