# 拖动上架与紧凑服务器面板

依据：用户要求“当前无法上架，应允许拖动上架，服务器应该小一点”。

- [x] 先添加 Qt 拖放事件测试，验证槽位映射、冲突、越界、跨柜、原位置释放、旧设备首次上架和保存失败。
- [x] 为服务器面板添加拖动阈值、仅携带设备 ID 与页面随机令牌的 MIME、硬件外观拖动图。
- [x] 机柜根据鼠标所在 U 位预览整个占用范围；有效时绿色，冲突 / 越界时红色，提交前重新检查当前设备与位置。
- [x] 尚无机柜时，首次拖放原子创建 A01 / 42U 机柜并上架到 U01，不复制设备。
- [x] 使用拖动状态延迟 UI 重建，避免在 QDrag.exec 期间删除拖动源；取消时保持原位置。
- [x] 缩小待上架面板到 260×54，每 U 显示高度改为 30px；待上架区移到机柜上方，支持边缘自动滚动。
- [x] 独立代码审查无重要问题；测试与截图验证通过后重新打开源码版并提交 GitHub。

验证包括 Qt dragEnter / dragMove / drop 事件、鼠标移动触发拖动、模拟 QDrag.exec 中落位与取消、配置重新加载、无效和外部拖动拒绝。审查额外检查了 42U 首尾与中间槽位映射。未连接真实 SSH 设备。
