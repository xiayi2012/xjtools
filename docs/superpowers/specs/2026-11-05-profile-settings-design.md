# 头像菜单与设置窗口

主导航左下角增加头像与本地显示名称，点击弹出个人中心、设置、退出登录三个选项。展开和收起侧栏时均保留头像入口。沿用浅灰底、白色内容区及深青绿选中状态。

设置使用单例非模态独立窗口，左侧两个分类“大模型配置”“定时巡检配置”，右侧直接复用现有页面实例。关闭设置只隐藏窗口，不终止任务或销毁编辑内容。主导航移除原来的大模型配置和定时巡检，首页原快捷入口打开设置并定位对应分类。现有定时任务、配置读写路径及保存后返回模型列表的行为保持一致。

个人中心管理本地显示名称，保存至本地 profile.json 并更新导航头像文字。不创建不存在的网络账号或认证状态；未设置时显示“本地用户”。空名称不可保存，保存失败保留输入并提示。

用户选择“退出登录”退出整个程序，复用托盘退出逻辑；已有运维、连接、定时巡检与分析任务的退出保护继续有效。

验证侧栏入口、菜单操作、两个设置分类及首页跳转、设置关闭后主页面与任务不变、个人资料保存和失败、退出保护。
