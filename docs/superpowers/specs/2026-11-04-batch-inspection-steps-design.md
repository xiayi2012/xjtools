# 批量巡检分步流程

按用户指定的“选择设备 → 下一步选择巡检项 → 下一步执行并显示各设备百分比 → 导出报告”调整现有页面。

采用同页三步切换，避免额外弹窗和左侧导航跳转。弹窗向导会增加窗口切换；折叠当前两栏仍会混合选择与执行，因此本次不采用。

第一步只显示设备选择表、全选/取消/刷新和下一步，无设备勾选时不可前进。第二步只显示巡检项及已选设备数量，支持返回；无检查项不可前进。第三步先显示此次设备的名称、地址、产品、状态、进度与报告操作，隐藏巡检项及输出，点击“开始巡检”才启动任务；开始前可返回修改巡检项。执行期间不可返回或再次启动，可停止；结束后可重新选择设备或导出报告。

各设备按现有顺序、独立 SSH 连接执行，单台连接失败继续下一台。增加设备进度信号，以采集完的检查项数除以总检查项数计算百分比；连接中为 0%，全部采集完成为 100%。失败和取消保留真实进度并标明状态；排队取消为 0%。百分比反映检查项完成数量，不估算时间或健康程度。

结果按设备 ID 和任务 ID 绑定，保留历史记录、原始报告、单设备分析导出与全量原始报告导出。原始输出继续内部保存，不在流程中展开。执行中不可导出；未开始的取消设备不生成空报告。导出失败保留结果并显示错误。报告保存成功后自动打开所在文件夹，批量导出只打开一次目录；取消或保存失败不打开目录，目录打开失败不影响已保存报告。

选择快照在开始任务时固定；设备在第二步被删除时返回选择设备并要求重新确认。正在导出或其他任务冲突时不允许开始新巡检。单设备一键巡检弹窗保持原有流程。

验证：三步可见性与前进条件、返回保留选择、检查项进度、失败继续、停止后真实百分比、每设备报告与历史绑定、全量导出和截图检查。
