# 设备管理工作台排版

用户要求：重新美化和排版设备管理界面。沿用已确认的拟物机柜、紧凑服务器与拖动上架交互。

## 视觉与布局

- 标题与新增入口独立一行；搜索、机房筛选及三视图切换整合为一条工具栏。
- 以深蓝灰 `#203b49` 为主要文字、青绿 `#159b8c` 为主要动作、浅蓝灰 `#eff4f7` 为机柜画布、白色为面板背景。
- 机柜工作区与设备详情左右分区，间隔 12px；统一边框、圆角、字号与次要文字层级。
- 待上架设备固定在机柜滚动区域外，使用独立横向滚动条，浏览长机柜时不移动拖动源。
- 机柜标题显示名称与机房，容量占用条仅表示实际 U 位使用率；编辑、删除收进机柜齿轮菜单。
- 设备详情使用紧凑信息卡、位置和连接状态、最近巡检、双列操作区。卡片直接提供连接 / 断开，root 等操作保留齿轮菜单。
- 未选中设备时显示选择入口说明；无机柜时在画布内显示原生机柜插画、拖放说明和创建入口。

## 验证

- 保留现有资产、连接、巡检、报告与拖动规则，不修改配置结构。
- 新布局测试验证：待上架设备不随机柜垂直滚动；详情卡紧凑；断开连接信号正确；主要操作为双列。
- 104 项自动测试通过，覆盖此前拖放、冲突、取消、保存失败、root 状态与目标设备绑定。
- 通过隔离示例数据检查 12U、42U、空机柜和选中设备的 Qt 截图；独立审查未发现重要回归，并额外检查了 20 台待上架设备的横向可达性。
- 本次仅改界面，不连接真实 SSH 设备。
