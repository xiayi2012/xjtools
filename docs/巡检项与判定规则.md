# 日常只读巡检基线

本项目内置巡检面向常见 GNU/Linux 服务器的日常运行检查。下列阈值是项目默认值，应按业务容量、维护策略与历史趋势调整，不等同于等保、CIS 或其他合规认证标准。单次巡检不替代持续监控和故障根因分析。

## 执行范围

- 内置项仅执行信息读取，不提权、不安装软件、不修改配置、不清理文件、不重启服务。
- 不默认 ping 公网地址，不扫描未知目标，不进行在线更新或软件源探测。
- 自定义脚本仍由用户维护；只读约束不自动扩展到用户自行添加的脚本。
- 常规单项上限为 20 秒；日志最多 50 条，进程 TOP 最多 10 条，僵尸进程最多展示 20 条，防火墙清单最多 100 行。
- 没有配置真实服务名、证书路径等业务信息时，不使用演示路径或猜测厂商命令。证书有效期、产品专属健康检查可在脚本库中按实际环境补充。
- 内置命令使用完成标记识别中断；只有部分数据或缺少必要字段时，不能判为正常。

## 判定规则

| 指标 | 默认规则 | 说明 |
|---|---|---|
| 文件系统空间和 inode | ≥80% 警告，≥90% 异常 | 仅本地文件系统；排除 tmpfs、devtmpfs、squashfs 和 iso9660 |
| 内存 | 有效使用率≥80% 警告，≥90% 异常 | 有效使用率为 (MemTotal−MemAvailable)/MemTotal；不用 MemFree 代替可用内存 |
| 系统负载 | 5分钟负载/核心数≥1 警告，≥2 异常 | 1分钟每核负载≥1仅作突升警告；负载不是CPU使用率，需结合I/O情况 |
| CPU使用率 | 1秒采样≥90% 警告 | 从两次 /proc/stat 差值计算总体使用率；不声称是每核使用率或长期趋势 |
| 时间同步 | NTPSynchronized=no 为警告 | 同步状态未知则为未获取；不使用本机时间与UTC时间相减伪造时钟偏差 |
| systemd服务 | failed 状态为异常 | 不把正常停止或未启用的服务一律判成故障；非systemd环境为不适用 |
| 僵尸进程 | 数量>0 警告 | 提示核查父进程，不自动终止进程 |
| UID 0账户 | 存在root之外的UID 0账户为警告 | 仅核对本地passwd，不读取shadow、私钥和密码 |
| 错误日志 | 有近期错误线索为警告 | 不直接确认根因；普通用户可见范围可能受限，空结果不能证明全系统无错误 |
| 容器 | restarting、unhealthy、dead 警告 | exited、paused等只采集，不脱离业务预期直接判成故障 |
| 网卡计数 | 非零累计错误或丢包给出复核警告 | 累计计数不是实时吞吐量，需二次采样确认增长情况 |

## 结果状态

- 正常：本次获得必要字段，且该规则未达到默认告警阈值。
- 警告：需要复核的指标或线索，不等于业务已经不可用。
- 异常：已获得满足明确异常规则的证据。
- 未获取：命令失败、权限不足、解析失败、空输出或采集未完成。
- 仅采集：信息清单或需要结合业务基线人工核对的项目，不计入正常数量。
- 不适用：当前没有对应工具或运行环境，不视为正常，也不等同于故障。

报告分别统计以上状态，未执行的勾选项按未获取展示，不虚构样本或正常数量。AI分析只补充解释，不覆盖命令证据的状态判定。

## 统一清单

共 23 项，默认勾选 16 项，其余按需勾选。鼠标悬停在巡检项上可查看判定依据。

| 分类 | 巡检项 | 默认勾选 | 依据与范围 |
|---|---|---|---|
| 系统信息 | 主机与系统信息 | 是 | 采集主机、内核、发行版和运行时间，仅作资产信息，不据此判定健康。 |
| 系统信息 | 系统时间与同步状态 | 是 | 读取时间同步状态；未同步为警告，不把 UTC 与本地时区的差异当作时钟偏移。 |
| 资源容量 | 系统负载与CPU核心数 | 是 | 按核心数归一化：5分钟负载/核心数≥1警告、≥2异常；1分钟突升仅提示复核。负载不是CPU使用率。 |
| 资源容量 | CPU使用率（1秒采样） | 是 | 两次读取 /proc/stat 计算总体使用率；单次采样≥90%给出警告，不据此认定持续故障。 |
| 资源容量 | 内存可用量与交换空间 | 是 | 以 (MemTotal-MemAvailable)/MemTotal 估算压力，≥80%警告、≥90%异常；缺少MemAvailable不猜测。 |
| 资源容量 | CPU使用率TOP10进程 | 是 | 展示ps统计的进程CPU占比和运行时间；仅输出进程名，不采集可能含口令的完整参数。 |
| 资源容量 | 内存使用率TOP10进程 | 是 | 采集进程内存占比、RSS与运行时长，供进一步定位。 |
| 存储容量 | 本地文件系统空间使用率 | 是 | 本地文件系统使用率≥80%警告、≥90%异常；排除内存和只读镜像文件系统。 |
| 存储容量 | 本地文件系统inode使用率 | 是 | inode使用率≥80%警告、≥90%异常，避免有剩余空间却无法创建文件。 |
| 存储容量 | 块设备与挂载清单 | 否 | 仅采集设备与挂载关系；未挂载分区可能是预留盘、交换分区或成员盘，不直接报警。 |
| 服务进程 | systemd失败服务 | 是 | 只检查failed服务；不把未启用或正常停止的服务直接判为异常。 |
| 服务进程 | 僵尸进程检查 | 是 | 发现僵尸进程提示核查父进程；只展示前20条，不执行终止操作。 |
| 网络状态 | 网络接口与路由清单 | 是 | 采集地址与路由；不主动访问外网，不把未使用接口DOWN直接判成故障。 |
| 网络状态 | 本机监听端口清单 | 是 | 仅采集监听端口；普通用户可能看不到其他用户进程，不按端口号猜测业务风险。 |
| 网络状态 | 网卡累计收发与错误计数 | 否 | 累计计数不是实时吞吐量；有错误或丢包只提示结合时间差和业务情况复核。 |
| 网络状态 | DNS配置清单 | 是 | 只读取解析器配置，不声称已经验证实际解析或公网连通性。 |
| 安全核查 | UID为0的账户核查 | 是 | 发现root之外的UID 0账户给出警告；不读取shadow、密钥或密码内容。 |
| 安全核查 | 最近10次登录记录 | 否 | 按需查看登录记录，不将无记录或某个来源IP直接判成入侵。 |
| 安全核查 | 防火墙规则清单（人工核对） | 否 | 可选读取规则，最多100行；存在规则不证明防护完整，需按业务策略核对，权限不足为未获取。 |
| 安全核查 | SSH认证配置（人工核对） | 否 | 读取有效认证配置，仅供按组织策略核对；权限不足明确标为未获取，不修改配置。 |
| 日志核查 | 近24小时系统错误日志 | 是 | 最多50条；存在错误日志给出待核查警告。非root读取范围可能受限，不据空输出宣称系统无错误。 |
| 日志核查 | 近24小时内核错误日志 | 否 | 可选的内核错误线索，覆盖部分OOM和硬件错误；日志不等于已确认根因。 |
| 容器检查 | Docker容器状态与健康信息 | 否 | 可选；未安装Docker为不适用，权限不足为未获取。重启中或unhealthy提示警告，正常退出不一律报警。 |

## 实现与验证

清单与判定逻辑位于 `src/scripts/inspection_catalog.py`，手动巡检、旧选择页面、定时巡检和加载器共同引用，避免通过读取界面源码恢复巡检项。定时巡检使用默认勾选项，并继续加载用户维护的产品脚本。

Windows 下可运行：

```powershell
.\venv\Scripts\python.exe -X utf8 -m pytest tests -q
.\venv\Scripts\python.exe -X utf8 -m src.main
```

自动测试覆盖阈值边界、空输出与权限不足、正常和异常状态并存、采集中断、命令Shell语法、定时与手动清单一致性、异常证据保留以及报告统计。Windows客户端上的样例测试不代表在所有Linux发行版和实际设备上已经验证；上线前应在授权测试机复核命令可用性与采集权限。
